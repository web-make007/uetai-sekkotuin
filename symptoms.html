腰・骨盤

慢性的な腰痛

長年の腰痛、ぎっくり腰の繰り返し、デスクワーク後の鈍い痛み——。原因は姿勢の歪みや筋肉のアンバランスにあることが多く、根本からのケアが大切です。

こんな方に 朝起きると腰が重い / 立ち上がるとき痛む / 長時間座れない
詳しく見る ›
肩・首

肩こり・首こり

スマホやPC作業による猫背・ストレートネックが原因の肩こり。揉みほぐすだけでなく、姿勢から整えることで再発しにくい体に。

こんな方に 夕方になると肩が重い / 頭痛や吐き気を伴う / 揉んでもすぐ戻る
詳しく見る ›
肩・首

頭痛・眼精疲労

頭痛薬が手放せない、目の奥が痛い——。多くは首・肩の緊張からくる「緊張型頭痛」。原因の筋肉と姿勢にアプローチします。

こんな方に 月に何度も頭痛がある / 目の奥が重い / 肩こりも併発している
詳しく見る ›
腰・骨盤

産後の骨盤の歪み

出産で開いた骨盤を、無理なくやさしく整えていきます。お子様連れOK。キッズスペースもご用意しています。

こんな方に 骨盤が広がった気がする / 産前のズボンが入らない / 腰や恥骨が痛む
詳しく見る ›
脚・足

膝の痛み・違和感

階段の上り下り、立ち上がりで痛む膝。膝そのものではなく、骨盤や足首のバランスが原因のことも。全体を見て施術します。

こんな方に 階段で痛む / 正座ができない / 歩くと違和感がある
詳しく見る ›
自律神経

不眠・自律神経の乱れ

寝つきが悪い、疲れが抜けない、めまいやだるさ——。背骨・骨盤の歪みから自律神経が乱れていることがあります。

こんな方に 夜眠れない / 疲れが取れない / なんとなく体調が悪い日が続く
詳しく見る ›
スポーツ・事故

スポーツでのケガ

捻挫・肉離れ・テニス肘などのスポーツ障害に対応。早期回復とパフォーマンス向上を目指したリハビリ・コンディショニングを行います。

こんな方に 試合前にケガを治したい / 同じ箇所を繰り返す / 復帰までサポートしてほしい

症状への治療アプローチ APPROACH

症状や状態に合わせて、4つのアプローチを組み合わせて施術いたします。

手技療法

筋肉や関節を、手の感覚で丁寧に整えていく当院のベースとなる施術です。

骨格矯正

姿勢分析の結果に基づき、骨盤・背骨を整えて根本から改善を目指します。

電気療法

深部の筋肉に届く電気刺激で、痛みの緩和と血流改善をサポートします。

運動療法

セルフケアやストレッチをお伝えし、再発予防まで一緒に取り組みます。
